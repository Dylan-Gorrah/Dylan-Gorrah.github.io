Java tutoring for first-years at IIE Rosebank College (2025 to now).

## Parts
- **Headline** (`.big`): "I teach Java to *first-years.*", with the subheading "From a high risk module to safe." (`.lead2`) underneath.
- **Pass-rate meter** (`.meter`): a crossed-out "65%" next to a big "85%" that counts up. The bar grows in two parts: grey (`.a`, 0–65%), then copper (`.b`, 65–85%). Widths are set in `tutoring.css` (`.meter-bar .a/.b`), so update them there if the numbers change.
- **Bullets** (`.pts`): what you teach and make.
- **Award** (`.award`): dark strip with a star, "Best Tutor/Teacher Award".
